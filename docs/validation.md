# Проверка версии портфолио

Проверено 19 октября 2026 года на локальном PostgreSQL 18, Python 3.13 и PyQt5. Исходная TheaterDB не использовалась для изменяющих операций.

- 8 интеграционных тестов прошли на отдельной theater_portfolio_test.
- 7 аналитических SQL-примеров и запрос сверки счётчиков выполнились на демонстрационной схеме.
- 7 реальных окон PyQt созданы и отрисованы вне экрана с вымышленными данными. Это проверка загрузки форм, а не полное ручное тестирование каждого клика.
- BPMN содержит события, задачи, шлюз, дорожки и координаты BPMN DI; файл XML проверен на целостность ссылок при сборке.

## Что не проверялось

Нагрузочные испытания, развёртывание на Linux/macOS, запуск через Docker на этом ноутбуке и эксплуатация с реальными пользователями не проводились. В репозитории есть Compose для воспроизведения окружения, но локальная проверка использовала установленный PostgreSQL.

Прикладные роли не заменяют серверную авторизацию: desktop-клиент имеет реквизиты БД. Нет rate limiting, платёжного шлюза и API. Повторная команда покупки создаёт ещё один билет, если места есть; идемпотентный ключ покупки пока отсутствует.
